# Задание 3: RAG-система (Поиск по базе знаний)

Мини-сервис: загружает текстовый документ (например, регламент компании),
разбивает на чанки, кодирует эмбеддингами и сохраняет в векторную БД FAISS.
По текстовому вопросу находит релевантный фрагмент и генерирует точный ответ
через Claude (Anthropic API).

## Архитектура

- **Эмбеддинги**: `sentence-transformers` (`paraphrase-multilingual-MiniLM-L12-v2`,
  локально, без API-ключа) — Anthropic API не предоставляет endpoint эмбеддингов,
  поэтому для векторизации используется отдельная лёгкая модель, а Claude — только
  для генерации финального ответа.
- **Векторная БД**: FAISS (`IndexFlatIP` + нормализация векторов = косинусная близость),
  индекс персистится на диск (`data/index.faiss`, `data/chunks.json`).
- **Генерация ответа**: Claude (`claude-sonnet-5`) отвечает строго на основе найденных
  фрагментов и указывает, на какие из них опирается.

## Запуск

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your-api-key-here
uvicorn main:app --reload --port 8001
```

## Использование

```bash
# Загрузить документ
curl -X POST http://localhost:8001/ingest -F "file=@sample_regulation.txt"

# Задать вопрос
curl -X POST http://localhost:8001/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "В течение какого времени нужно предоставить больничный лист?"}'
```

Ответ:

```json
{
  "answer": "Больничный лист необходимо предоставить в течение 3 рабочих дней с момента открытия (Фрагмент 3).",
  "sources": [
    {"text": "5. Отпуск и больничные...", "score": 0.71}
  ]
}
```

## Файлы

- `chunking.py` — разбиение текста на перекрывающиеся чанки
- `vector_store.py` — обёртка над FAISS (эмбеддинги, индекс, персистентность)
- `qa.py` — промпт и вызов Claude для генерации ответа
- `main.py` — FastAPI-приложение (`/ingest`, `/ask`)
- `sample_regulation.txt` — тестовый регламент компании для проверки
