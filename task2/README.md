# Задание 2: Локальный классификатор текстовых заявок

Классификация текстовых ТЗ по 5 категориям: «Веб-разработка», «Мобильное приложение»,
«Дизайн», «Аналитика», «Маркетинг».

## Датасет

`dataset.py` содержит вручную составленный датасет — по 10 примеров на категорию
(50 всего), приближённых к формулировкам реальных ТЗ. Генерируется в `tz_dataset.csv`.

## Модель

TF-IDF на символьных n-граммах (3-5, `char_wb`) + логистическая регрессия
(`scikit-learn`). Символьные n-граммы выбраны вместо словных по результатам
кросс-валидации — на маленьком датасете они устойчивее к разным словоформам.

Оценка качества — 5-fold стратифицированная кросс-валидация (единичный
train/test split слишком шумный на 50 примерах): **accuracy ≈ 0.54**.
Для такого малого и намеренно пересекающегося по лексике датасета
(«продвижение» встречается и в маркетинге, и в вебе) это ожидаемый результат;
в проде датасет нужно расширять до сотен примеров на класс.

## Запуск

```bash
pip install -r requirements.txt
python train.py            # обучает модель, печатает отчёт, сохраняет tz_classifier.joblib
python predict.py "Разработать лендинг на React с формой заявки"
```
